## 1. Was ist die Versionskontrole?
### Ein Versionskontrollsystem (VCS) ist ein Programm, das Änderungen an einer Sammlung von Dateien verfolgt.
#### Es ermöglicht, frühere Versionen einzelner Dateien oder des gesamten Projekts leicht abzurufen und unterstützt mehrere Teammitglieder dabei, gleichzeitig an einem Projekt zu arbeiten, ohne sich gegenseitig zu stören.

### Mit einem VCS kann man:
- alle Änderungen sehen, inklusive wer sie wann gemacht hat
- zu jeder Änderung eine Nachricht mit dem Grund hinzufügen
- frühere Versionen einzelner Dateien oder des ganzen Projekts wiederherstellen
- Verzweigungen (Branches) erstellen, um verschiedene Änderungen oder Experimente parallel zu bearbeiten, ohne den Hauptzweig zu beeinflussen, und diese später wieder zusammenführen
- Versionen mit Tags markieren, z. B. für ein Release

## 3. IPT1 – Erster Lernnachweis
### In IPT1 habe ich gelernt, wie man mit Git und GitHub arbeitet.
#### Ich verstehe Ich verstehe jetzt den Ablauf Issue → Branch → Commit → Pull Request und kann einfache Änderungen selbstständig versionieren.

### Issue
- Was?: Eine Aufgabe oder ein Problem 
- Wozu?: um zu wissen, was gemacht werden muss

### Branch
- Was?: Ein eigener Arbeitsweg
- Wozu?: damit man getrennt vom Hauptcode arbeiten kann, ohne etwas kaputt zu machen

### Commit
- Was?: Eine gespeicherte Änderung
- Wozu?: um zu festhalten, was man geändert hat & warum

### Pull Request
- Was?: Eine Anfrage, deine Änderungen in den Hauptcode einzubauen
- Wozu?: Andere können prüfen, ob alles korrekt ist
